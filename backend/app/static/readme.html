Overview

This solution combines a FastAPI backend, a React-based operations dashboard, a Bolna voice agent, and integrations with Supabase and Cliniko to create a clinic receptionist experience that can manage appointments, follow-ups, and live call workflows.

System Components

  • Backend API for tool execution and webhooks
  • Frontend dashboard for operations and monitoring
  • Bolna voice agent for conversational appointment handling
  • Supabase for structured operational data
  • Cliniko for practitioner and appointment synchronization

Operational Capabilities

  • Appointment booking, rescheduling, and cancellation
  • Returning patient recognition and new patient registration
  • Availability lookup and live slot confirmation
  • Follow-up logging and call continuation support
  • Clinic information response from live backend sources

Deployment and Telephony Notes

  • Use the public Render backend URL for all Bolna tool and webhook configuration.
  • Ensure Twilio numbers are verified for both inbound and outbound testing.
  • For inbound calls, use an international verified number rather than a domestic test number.
