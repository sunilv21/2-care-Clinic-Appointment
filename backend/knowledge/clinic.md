# Aarogya Multi-Speciality Clinic

Aarogya Multi-Speciality Clinic is a multi-branch outpatient clinic in Bengaluru offering General
Medicine, Dermatology, and Pediatrics, with two locations serving patients across the city.

- Currency: Indian Rupees (₹ / INR)
- Timezone: Asia/Kolkata (IST)
- Appointment types: Standard Appointment (30 min), First Appointment (45 min, for new patients or a
  new complaint), Follow-up (15 min)

For live doctor names, specialties, branch schedules, or open slots, the agent must always call the
appropriate tool (`get_doctors`, `get_branch_info`, `find_availability`) — this file never contains
that information because it changes.
